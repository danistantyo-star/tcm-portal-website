ISI FOLDER INI
==============
konten-awal.json  -> 14 proyek dan 22 sertifikat/dokumen yang sudah disiapkan
                     (15 di antaranya sudah punya gambar ber-watermark di assets/dok).

Cara memakainya:
  1. Pasang dan aktifkan tema TCM v3.1 - halaman-halaman situs otomatis dibuat
     dan Halaman Depan otomatis diatur saat tema aktif.
  2. Di menu admin akan muncul  Alat (Tools) -> Impor Konten TCM.
  3. Klik tombol "Impor sekarang". Proses ini hanya perlu dijalankan SEKALI.
  4. Masih di halaman yang sama, jalankan juga "Pasang gambar" supaya foto
     proyek dan gambar sertifikat terpasang otomatis sebagai Featured Image.
  5. Setelah itu buka menu Proyek dan Sertifikat untuk memeriksa hasilnya.

Berita TIDAK ikut diimpor - tulis lewat menu Pos (Posts) -> Tambah Baru.
Bahan artikel siap pakai ada di dokumen "TCM_bahan_berita".
