# Sumber aset referensi

Target yang diminta: https://www.ngodingpakeai.com/ . Diobservasi 15 Oktober 2026 melalui browser publik tanpa login; tidak memakai sesi pengguna, endpoint privat, atau kredensial.

- `logo.svg`: SVG logo pada tautan beranda. Namespace XML ditambahkan agar dapat ditampilkan sebagai file gambar mandiri.
- `open-sauce-sans-*.woff2`, `jetbrains-mono-*.woff2`: respons font publik dari `https://www.ngodingpakeai.com/assets/` dengan nama file yang dipertahankan.
- `card-*.svg`: SVG publik kartu beranda. Versi yang dipakai aplikasi ada di `src/assets/`, dengan gaya animasi browser dibekukan pada posisi teramati; ukurannya mengikuti crop referensi.
- `template-saas-0.png` sampai `template-saas-7.png`: delapan gambar publik dari detail Saas Template. Daftar URL hasil observasi ada dalam catatan template di `research/templates.md`.

Nama produk dan kredit sumber dipertahankan untuk mencocokkan referensi. Angka komunitas/harga bersifat snapshot. Tidak ada token autentikasi, bootstrap token, atau nilai kredensial yang disimpan bersama aset ini.
